# Vitality O1
**For more future updates and support you can buy the supporter version of our plugin here: https://linktw.in/lnScLo**
A modern, lightweight, and powerful Essentials-style utility plugin for Minecraft servers.

Built for Paper and modern Minecraft versions, VitalityO1 provides essential server management tools, player utilities, moderation features, economy support, teleportation systems, and performance-focused design in a single plugin.

## Features

### Player Utilities

* `/spawn` and `/setspawn`
* Multiple homes support
* `/home`, `/sethome`, `/delhome`
* `/back` command
* Safe teleportation system
* Teleport requests (`/tpa`, `/tpaccept`, `/tpdeny`)
* Warp management (`/warp`, `/setwarp`, `/delwarp`)

### Economy

* Player balances
* `/balance`
* `/pay`
* Administrative economy commands
* UUID-based data storage

### Moderation

* Kick players
* Ban players
* Mute system
* Warning system
* Staff chat
* Configurable punishments

### Chat Features

* Custom chat formatting
* Placeholder support
* Anti-spam protection
* Optional chat filtering
* Private messaging system
* Reply command

### Utility Commands

* Fly mode
* God mode
* Heal
* Feed
* Vanish
* Item repair

### Server Management

* Spawn protection
* Configurable safe zones
* Modular feature system
* Easy configuration
* Reload support

### Performance Focused

* Lightweight architecture
* Efficient event handling
* Optimized data management
* Designed for modern Paper servers

## Supported Platforms

* Paper
* Purpur
* Folia (planned)

## Requirements

* Java 21
* Minecraft 1.21+
* Paper-based server software

**->** ## Installation

1. Download the latest release.
2. Place the `.jar` file into your server's `plugins` folder.
3. Restart the server.
4. Configure the plugin through `config.yml`.

## Permissions

VitalityO1 includes a comprehensive permission system for all commands and administrative features.

Examples:

* `vitalityo1.spawn`
* `vitalityo1.home`
* `vitalityo1.warp`
* `vitalityo1.admin`
* `vitalityo1.moderation.*`
